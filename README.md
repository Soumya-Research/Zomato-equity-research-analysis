# Zomato Equity Research & Financial Analysis

This project analyzes Zomato’s financial performance, profitability trends, and business strategy using publicly available financial data and Excel-based analysis.

## Key Areas Covered

* Revenue Growth Analysis
* Profitability Trends
* Operating Margins
* Blinkit Acquisition Impact
* Peer Benchmarking
* Business Insights

## Tools Used

* Microsoft Excel
* Financial Statement Analysis
* Ratio Analysis
* Data Visualization

## Objective

To understand the financial and operational drivers behind Zomato’s growth and long-term profitability potential.
